# ☕🐱 Michi Café — Curso de Java + Spring Boot + MongoDB
## Microservicios para personas que nunca han programado

> Aprenderás a construir un sistema real usando la analogía de **Michi Café**,
> una cafetería temática de gatitos donde cada parte del sistema tiene un rol claro y divertido.

---

## ¿Qué vas a construir?

Al terminar este curso tendrás funcionando un sistema completo de microservicios:
una aplicación real con base de datos, múltiples servicios independientes y todo
desplegado con Docker. Exactamente como lo hacen las empresas grandes.

---

## 🗺️ Cómo está organizado este curso

El curso tiene **dos partes** que se complementan:

### 📚 Parte 1 — Teoría y Conceptos
Aquí aprenderás todo lo necesario para entender qué estás haciendo y por qué.
Cada concepto viene explicado con analogías del Michi Café, ejemplos de código
comentados línea por línea y sin dar nada por sentado.

### 🛠️ Parte 2 — Proyecto Guiado
Aquí construyes el Michi Café real, paso a paso, clic a clic en IntelliJ IDEA.
Cada paso te dice exactamente qué hacer: qué menú abrir, qué escribir, dónde hacer clic.
Cuando necesites recordar un concepto, hay un enlace directo a la sección teórica.
