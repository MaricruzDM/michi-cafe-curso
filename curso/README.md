# ☕🐱 Curso: Java + Spring Boot + MongoDB con Microservicios
## Para personas sin experiencia en programación

> Aprenderás a construir un sistema real usando la analogía de **Michi Café**,
> una cafetería temática de gatitos donde cada parte del sistema tiene un rol claro y divertido.

---

## ¿Qué vas a aprender?

Al terminar este curso serás capaz de:
- Entender qué es la programación y por qué Java es tan usado en empresas
- Crear APIs REST con Spring Boot
- Guardar y consultar datos en MongoDB
- Dividir una aplicación en microservicios
- Conectar servicios entre sí

---
