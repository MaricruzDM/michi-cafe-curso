    ☕🐱 Michi Café — Curso de Java + Spring Boot + MongoDB¶

    Microservicios para personas que nunca han programado¶

    Aprenderás a construir un sistema real usando la analogía de Michi Café, una cafetería temática de gatitos donde cada parte del sistema tiene un rol claro y divertido.

    ¿Qué vas a construir?¶

    Al terminar este curso tendrás funcionando un sistema completo de microservicios: una aplicación real con base de datos, múltiples servicios independientes y todo desplegado con Docker. Exactamente como lo hacen las empresas grandes.

    🗺️ Cómo está organizado este curso¶

    El curso tiene dos partes que se complementan:

    📚 Parte 1 — Teoría y Conceptos¶

    Aquí aprenderás todo lo necesario para entender qué estás haciendo y por qué. Cada concepto viene explicado con analogías del Michi Café, ejemplos de código comentados línea por línea y sin dar nada por sentado.

    🛠️ Parte 2 — Proyecto Guiado¶

    Aquí construyes el Michi Café real, paso a paso, clic a clic en IntelliJ IDEA. Cada paso te dice exactamente qué hacer: qué menú abrir, qué escribir, dónde hacer clic. Cuando necesites recordar un concepto, hay un enlace directo a la sección teórica.

    06 MongoDB Base de datos de documentos

    08 Microservicios Arquitectura independiente
    09 Servicio Clientes Primer microservicio
    10 Servicio Pedidos Segundo microservicio
    11 Servicio Bebidas Tercer microservicio
    12 Comunicación Servicios hablando entre sí

    14 Docker Empaquetando todo

    P02 Primer proyecto Spring Boot Estructura base del Michi Café

    🛠️ Herramientas que usarás¶

    Herramienta Versión Para qué
    Java (JDK) 17 LTS El lenguaje de programación
    Spring Boot 4.1.0 El framework para crear el servidor
    MongoDB 7.x La base de datos
    IntelliJ IDEA Community (gratis) El editor de código
    Postman Última Para probar las APIs
    Docker Desktop Última Para empaquetar todo

    Cómo usar este curso¶

    Si eres completamente nuevo: Lee la Parte 1 en orden, luego ve a la Parte 2.

    Si quieres ir directo al código: Ve a la Parte 2 y consulta la Parte 1 cuando aparezca un enlace de referencia.

    Cada módulo tiene: - 📖 Explicación con analogías del Michi Café - 💡 Conceptos explicados sin jerga técnica - 💻 Código comentado línea por línea - 🧪 Ejercicios de comprensión - ✅ Resumen del módulo
